# 归归统一 UI 开发规范

本规范适用于所有新增或修改的主页面、二级页面、设置页、对话框和数据列表。开发前须与 `UI_I18N_RULES.md` 一并阅读。

## 页面骨架

- 使用统一的“标题、说明、内容、操作”层级；外边距优先 24，内部间距从 4 / 8 / 12 / 16 / 24 / 32 中选取。
- 优先使用动态布局、Dock、Anchor 和 AutoSize。不得按中文长度固定页面宽度。
- 标题、正文、辅助文字和状态文字沿用主程序字体与 `UiStyle` 色彩，不依赖原生 WinForms 默认立体外观。

## 控件和列表

- 按钮统一使用 `UiStyle.NewButton` / `UiStyle.StyleButton`；同级操作保持相同高度和视觉层级。
- 表格统一使用 `UiStyle.StyleGrid`，支持完整行选择、明确空状态、稳定行高与单行表头。短字段自动宽度，长字段 Fill。
- 卡片、边框、分隔线、选择色、警告色和错误色复用 `UiStyle`，不得在页面内另建一套状态颜色。
- 可供用户提交的问题数据必须支持选择、Ctrl/Shift 多选、Ctrl+A、Ctrl+C 和右键复制；完整参数放在可选择文本或详情区域中。

## 完成检查

- 页面结构、间距、字体、按钮、表格和状态样式是否统一，是否残留明显默认 WinForms 风格。
- `zh-CN`、`en-US`、`de-DE` 与 `_template` 的 Key、占位符是否一致；德文是否截断或产生无意义换行。
- 100% / 125% / 150% DPI、默认尺寸、最小尺寸和拉伸状态是否无重叠。
- 新 UI 是否引入持续磁盘写入、重复全表测量或其他明显性能损耗。

一个概念只使用一个字段；文案应简洁，但不得删除决定功能含义的核心词。
