# 全软件按钮启用 / 禁用状态规则表（V1.11.23）

本规则用于统一主界面和二级管理页面的按钮行为。原则：**只有当前操作确实可执行时按钮才保持可用；条件不足时直接灰显。** 禁用状态统一使用浅灰背景、浅灰文字和浅灰边框。

## 顶部状态筛选一致性（V1.11.12）

- 状态筛选的可点击性不由计数决定；即使某状态为 `0`，用户仍可进入对应空列表。
- “重复”顶部入口是标准筛选按钮；底部“暂不整理”链接才承担“进入筛选并定位第一条”的动作入口。
- “待确认”在有项目时仍执行“切换筛选 + 定位第一条 + 必要时展开详情”；为 `0` 时则退化为普通空状态筛选。

## 待确认项目与主操作规则（V1.11.11）

- “待确认”指歧义或未识别等必须由用户介入的项目；这些项目保持原位，不进入本次移动计划。
- 只要仍存在 `CanMove=true` 的项目，待确认项目不得让“执行整理”整体灰显。
- 执行时同时存在待确认项目，必须给用户明确选择：整理可执行项目并暂时跳过待确认、进入待确认处理、取消。
- 可整理为 0、待确认为 N 时，主按钮改为“处理待确认（N）”，点击后直接切换到待确认视图、选中第一项并展开详情。
- 顶部“待确认 N”和底部“需要确认”链接都是主流程入口，不能只依赖右侧详情是否当前可见。

## 扫描期间交互规则

扫描预览运行时，窗口、预览列表、筛选、搜索、滚动和详情查看保持响应；原始/目标路径、扫描范围、文件类型、扫描数量、递归设置等会改变本轮上下文的控件锁定。执行整理、指定作者、排除、重命名、Delete 从预览移除等会改变计划的操作统一禁用。

## 执行期间统一锁定规则

执行整理开始后，所有会改变扫描条件、计划、目标路径或当前数据的控件统一锁定；进度条、执行状态和必要的状态信息继续保持可见。执行结束或安全停止后，按钮状态根据最新数据重新计算，而不是简单全部恢复为可用。

## 视觉规则

- 可用普通按钮：白色背景 + 正常文字 / 边框。
- 可用主操作按钮：保留主按钮强调样式。
- 可用危险操作按钮：保留危险色文字 / 边框。
- 禁用按钮：统一浅灰背景、浅灰文字、浅灰边框，并取消 Hand 光标。
- 禁用不是错误提示；真正的错误原因仍由底部状态、容量状态或安全检查信息解释。


## 首次使用底部引导

- 原始位置无效或未设置：底部显示可点击“第 1 步：请选择原始位置”，点击打开原始位置文件夹选择器。
- 原始位置有效、迁移位置无效或未设置：显示可点击“第 2 步：请选择迁移位置”，点击打开迁移位置文件夹选择器。
- 两个位置均有效且尚未形成扫描结果：显示可点击“第 3 步：点击‘扫描预览’开始识别”，点击等同于主按钮“扫描预览”。流程引导必须始终使用连续的“第 1 步 / 第 2 步 / 第 3 步”，不得混用“下一步”。
- 扫描完成后的统计状态不被首次使用引导覆盖。
