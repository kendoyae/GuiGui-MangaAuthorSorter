# 异步扫描与进度响应规则（V1.11.6）

## 目标

扫描预览不得长期占用 WinForms UI 线程。无论文件数量多少，主窗口都应保持可重绘、可移动、可最小化，并允许用户查看当前已有预览。

## 扫描阶段

1. **文件发现**：Everything SDK 返回可计数结果时使用确定进度；普通文件系统枚举因总数未知，使用 Marquee，并显示“已检查 N 个”。全局扫描排除规则在候选进入作者识别前应用。
2. **全部文件模式**：作者识别与目标规划按待处理文件数显示 `当前 / 总数`。
3. **筛选模式 Early Stop**：扫描数量大于 0 时，扫描数量表示当前扫描范围的目标结果数。本地分类按“最新 → 最旧”逐个处理，达到目标数后立即停止后续作者识别/规划；进度显示“已找到 X / 目标；已检查 Y 个候选文件”。
4. **在线解析兼容**：启用实时在线作者查询时，因在线结果可能改变本地分类，使用递增候选前缀分批分类和查询，并在目标满足后尽早停止。
5. **筛选结果重规划**：只对最终要显示/执行的匹配结果重新规划目标，避免候选前缀中未入选文件影响新作者分组。
6. **预览更新**：后台任务成功完成后才替换 `_plan`；取消或失败不会用半成品覆盖原预览。规则排除项作为独立显示数据并入预览层，但不进入 `_plan`。

## 扫描期间允许的交互

- 移动、最小化、最大化窗口以及切换到其他程序。
- 滚动、筛选、搜索当前已有预览。
- 查看当前选择的详情以及显示/隐藏详情面板。

## 扫描期间锁定的操作

- 原始位置、迁移位置和浏览按钮。
- 扫描范围、文件类型方案、扫描数量、递归扫描。
- 会影响目录规划的分组命名/归档设置入口。
- 执行整理。
- 指定作者、排除此文件、重命名文件、Delete 从预览移除等计划变更操作。

## 停止扫描

扫描开始后“扫描预览”切换为“停止扫描”。停止属于协作式取消：文件枚举、Everything 结果读取、作者规划循环会定期检查取消请求。若底层单次系统/API 调用尚未返回，界面仍保持响应，并在该调用返回后立即停止后续工作。

取消后：

- 不移动、不删除、不重命名任何实际文件。
- 不采用尚未完成的临时扫描结果。
- 保留扫描前的当前预览与执行安全状态。

## 与执行整理的关系

扫描与执行整理互斥。扫描运行时“执行整理”始终禁用；执行整理运行时不能开始扫描。V1.10.13 起的容量检查、执行前安全检查和跨盘 `.moving` 安全迁移逻辑保持不变。

## V1.11.6 Early Stop 边界

Early Stop 优化的是作者解析、作者/社团匹配、在线查询与目标规划等高成本阶段。为了保持“最新 → 最旧”的稳定顺序，并统一应用扩展名过滤、手工排除和全局扫描排除，候选文件的轻量枚举仍可能覆盖整个扫描范围。

`扫描数量 = 0` 仍表示处理全部符合当前扫描范围的结果，不触发 Early Stop。
