# 扫描性能日志格式

`ScanPerformance.log` 使用可读的紧凑文本格式。当前格式为 `GL1`，时间单位统一为毫秒。字段集合或含义变化时必须升级格式版本，禁止静默复用 `GL1`。

文件头：

```text
#GL1
#DATE=2026-10-05
#F=t,h,rs,ht,sh,pw,sp,fd,ti,cp,am,so,rm,ba,lr,uf,ui,tr,c,r
#UNIT=ms
#CTX|W=1|E=1|P=ESDK
```

上下文仅在变化时以 `@CTX` 记录。跨日期继续写入同一文件时用 `@DATE=yyyy-MM-dd` 更新日期。`W/E` 分别表示预热与 Everything，`P=ESDK/SYS` 表示 Everything 官方 SDK 或文件系统。

字段依次为：扫描时间、预热命中、点击时已就绪、命中类型（0 未命中 / 1 在途复用 / 2 点击前完整命中）、完整快照命中、预热等待、快照后台准备、文件发现、目标索引、候选准备、作者解析与匹配、结果排序、行模型生成、批量加入行、布局恢复、界面收尾、界面应用、总响应、候选数、结果数。

性能诊断默认关闭。关闭时不写扫描性能明细；后台预热本身永远不产生性能日志。开启后仅在用户实际执行一次扫描并完成界面应用时写入一条记录。
