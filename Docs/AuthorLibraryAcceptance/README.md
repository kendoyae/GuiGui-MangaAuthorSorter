# 作者库验收资料提交范围

提交 `performance.md` 和 `Final/results.md`：保留样本规模、功能结果、计时与差异分类，便于评审本次实现。测试源码和运行脚本也应提交，可在其他环境重新生成验收资料。

以下文件由测试生成，仅保留本机，不提交：

- `ui-*.png`：界面渲染截图，包括重复生成的语言及字体缩放版本。
- `prior-scan-differences.json`：逐文件对照证据，含真实作者名、文件名和本机路径。
- 本目录根部 `results.md`：常规回归生成的中间结果；最终验收摘要保留于 `Final/results.md`。

完整功能、备份恢复及性能说明见 [作者库整合说明](../UNIFIED_AUTHOR_LIBRARY.md)。真实用户数据库、设置、缓存和迁移备份均不属于工程源码。
