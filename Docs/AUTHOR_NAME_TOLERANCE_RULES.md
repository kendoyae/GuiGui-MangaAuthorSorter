# 作者目录名称容错规则（V1.10.26）

## 1. 自动安全匹配

以下差异允许自动匹配已有作者目录，命中后状态显示为“标准化”，并继续使用磁盘上的真实目录名，不会自动改名：

- 首尾空格。
- 连续多个空格压缩为一个。
- 全角空格、Tab 等空白统一。
- 括号前后的空格可忽略，例如 `作者 (abc)` 与 `作者(abc)`。
- 全角/半角英数字符及括号统一。
- Unicode 兼容字符使用 FormKC 规范化。
- 零宽空格、零宽连接符、BOM 等不可见字符忽略。
- 仅缺少一个配对右括号时自动补齐比较，例如 `自家発電処 (flanvia` ↔ `自家発電処 (flanvia)`。
- 英文字母大小写差异。

> 标准化只生成内部“比较键”，不会修改真实作者文件夹名称。

## 2. 只提示候选，不自动匹配

以下差异可能是同一作者，也可能具有实际含义，因此只生成候选并要求用户使用“指定作者...”确认：

- `・` / `·` / `･` 等中点差异。
- `-` / `－` / `–` / `—` 等横线差异。
- `~` / `～` / `〜` 等波浪线差异。
- 整体外层引号差异，例如 `「作者」` / `“作者”`。
- 多出一个末尾右括号。
- 末尾多出一个单点。

## 3. 禁止自动容错

以下规则风险较高，不自动匹配：

- 删除所有空格：`John Smith` ≠ `JohnSmith`。
- 删除所有标点或符号：`A-B` ≠ `AB`。
- 简体 ↔ 繁体自动转换。
- 平假名 ↔ 片假名自动转换。
- 罗马字 ↔ 日文名自动推断；此类关系应使用作者别名库。
- 姓名顺序自动交换。
- 编辑距离、错字/形近字模糊匹配。
- 子串匹配。

## 4. 歧义保护

如果两个或更多真实作者目录经过“安全标准化”后都能命中同一作者，程序必须保持歧义状态并要求用户确认，不能任选一个目录。

## 5. 无标签文件的已有目录前缀匹配

当结构化标签没有产生作者候选时，允许使用“完整已有作者目录名位于文件名开头”作为确定性候选。

- 文件名必须从完整作者身份开始，例如 `うるし原智志 コミック...` 可匹配目录 `うるし原智志`。
- 作者身份后必须是空格、括号、连接号、下划线、中点或斜线等明确边界。
- 不允许任意位置子串匹配，也不允许只命中作者名称的一部分。
- 多个已有目录同时满足时必须保留为候选冲突，不能按长度或目录顺序任选。
- 该规则只匹配已有作者目录，不据此自动创建新作者。
