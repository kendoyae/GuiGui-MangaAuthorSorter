# 模拟性能测试

V1.12.2 起，性能诊断页面提供“模拟性能测试”。该功能用于在不修改真实文件的前提下，对作者解析、实体匹配、目标规划、缓存复用和增量重算进行可重复的性能测试。

## 数据来源

- `GuiGuiAuthorIndex.db` 只读打开，仅从 `Artist` 实体抽取测试作者。
- 固定随机种子决定作者样本顺序；同一数据库、同一种子和同一数量可重复得到相同测试集。
- 可使用标准作者名、罗马名、别名或确定性混合名称生成虚拟文件名。

## 虚拟环境

测试使用 `Z:\GuiGuiSimulation\...` 形式的虚拟路径，并在内存中构建：

- 虚拟源文件；
- 虚拟已有作者目录；
- 虚拟目标已有文件；
- 可选的源文件同名目标文件；
- 虚拟整理结果。

模拟测试不会调用真实的 `File.Move`，不会创建、重命名、移动或删除真实文件，也不会写入正式 `FileIndex`、Recognition Cache、Destination Cache 或历史记录。`GuiGuiAuthorIndex.db` 仅执行只读查询。

## 复用正式逻辑

模拟测试不维护一套独立作者识别算法。`SimulationBenchmarkService` 调用正式 `ArchiveEngine.ResolvePlanVirtual`，复用文件名解析、作者实体匹配、已有作者目录匹配、目标路径规划和冲突判定。虚拟模式只替换目标目录/目标文件的物理查询来源。

## 测试模式

- **首次扫描**：所有虚拟源文件进入正式识别与规划逻辑。
- **缓存扫描**：先建立隔离的内存基线，再测量未变化文件直接复用计划缓存的路径；未变化文件不进入 Recognition。
- **增量扫描**：先建立内存基线，再按设置比例修改虚拟文件名，仅变化文件重新进入 Recognition，其余文件复用基线。
- **完整测试**：依次执行首次扫描、缓存扫描和增量扫描，便于横向比较。

## 主要参数

- 模拟源文件数量；
- 目标已有作者比例；
- 模拟目标已有文件数量；
- 是否生成与源文件同名的目标文件；
- 作者名称模式；
- 增量变化比例；
- 固定随机种子。

## 结果

报告包含：

- 缓存复用数量；
- 本轮重新计算数量；
- 索引变化数量；
- 匹配已有作者 / 新作者 / 歧义 / 未识别；
- 目标同名冲突 / 批次目标冲突；
- 模拟成功整理 / 模拟跳过；
- 识别与规划耗时、整理模拟耗时、总耗时；
- 虚拟数据准备耗时。

性能回归比较时应保持 `GuiGuiAuthorIndex.db`、测试数量、参数和固定随机种子一致。

## V1.12.4 实时进度与独立窗口

模拟测试运行期间会持续显示当前阶段、阶段进度、当前虚拟项目和已用时间。阶段覆盖数据库检查、作者抽取、虚拟源文件生成、目标环境构建、基线准备、识别/规划、缓存复用、增量变更、冲突检查、虚拟整理和结果汇总。

模拟窗口为独立非模态窗口。测试任务在后台执行，主窗口与“性能诊断”窗口不会因打开模拟测试而被禁用；关闭性能诊断窗口也不会关闭正在运行的模拟测试。模拟测试仍与正式缓存和真实文件操作隔离。



## V1.12.5 作者重复率与作者库索引模式

模拟源文件数量与“唯一作者数量”现在分离。例如 1,500 个源文件、300 个唯一作者，会稳定生成约 5 个文件/作者，更接近真实漫画库，而不是把每个文件都当成一个从未查询过的新作者。目标已有作者比例也按唯一作者集合计算。

新增作者库索引模式：

- **冷索引**：使用隔离的作者实体环境，不预先构建 `GuiGuiAuthorIndex.db` 内存身份索引；首次 Recognition 触发构建，构建时间计入首次扫描。
- **预热索引**：在 Recognition 前先构建内存身份索引，报告单独记录构建耗时；识别阶段用于衡量稳定运行状态下的查询性能。

`GuiGuiAuthorIndex.db` 的普通 Artist 查询不再逐作者执行多条随机 SQLite 查询。程序会一次性顺序读取 Artist、Alias、ProviderIdentity 和 ArtistGroup，建立只读 `NormalizedName -> EntityId`、实体身份名以及作者/社团关系索引。普通作者解析之后走内存查询；只有需要“社团 + 作者”关系约束的结构化消歧仍使用原有 SQLite 关系查询。

报告新增：唯一作者数量、平均每作者文件数、作者库索引模式、作者库内存索引构建耗时，以及 Artist / 查询键 / 身份名 / 关系数量。性能对比时应同时保持源文件数量、唯一作者数量、名称模式、索引模式和随机种子一致。
