# V1.12.10 作者实体库与公共库整合

## 管理入口

作者别名库的独立窗口、存储服务及写入路径已移除。所有作者与别名操作由 `AuthorEntities.json` 页面承担。`AuthorAliases.txt` 和历史中文名称 TXT 仅供首次迁移或显式导入，原文件保留，不再写入；以后修改旧 TXT 不会覆盖实体库。

页面包含：

- 用户实体：新增作者/社团，编辑标准名、罗马名、别名、禁用名称和用户确认状态，删除实体，导入 JSON/TXT，导出 JSON。删除别名保留作者；删除存在关系的实体前需先解除关系。
- 公共实体：只读搜索和分页查看公共资料，创建用户覆盖。原始资料及提供方身份可查看。
- 关系：新增作者与用户社团关系，编辑确认/禁用状态，解除关系。公共作者通过用户覆盖关联用户社团。作者和社团的名称空间分开，同名不自动互相转换。
- 冲突：查看重复标准名、罗马名、别名以及公共身份变化；按名称搜索。处理方式为确认一个候选、保留独立实体、待确认或禁用该名称。公共候选可明确选定并保存为用户实体。每次显示最多 500 条，其他冲突可通过搜索定位。
- 公共覆盖：编辑有效标准名、新增别名、禁用名称；查看原值、稳定身份及绑定状态；明确重新绑定或恢复公共原值。
- 文件夹规则：维护迁移保留的结构化作者/社团规则。这些规则不会被强制转换成单个作者。
- 查询缓存：查看在线查询状态，清理仅删除查询缓存，不删除用户实体、别名、关系、覆盖或冲突决定。

在线查询关闭持久化时，临时实体只存在于会话中。实体页可将其保存为用户实体或删除；保存保留提供方元数据，双方保存后保留关系。编辑临时关系前先保存两端实体。

## 文件与身份边界

`AuthorEntities.json` 使用 SchemaVersion=3：保留 Authors、Aliases、Circles、AuthorCircles、LookupCache；加入 CircleAliases、PublicOverrides、NameDecisions、迁移记录及 DataRevision。用户作者/社团采用各自唯一 EntityId，整数 Id 仅供本文件引用。旧 schema 自动读取兼容，显式保存升级。

`GuiGuiAuthorIndex.db` 始终只读，不写用户修改。用户覆盖独立存放于 JSON，不复制整份公共库，不把 SQLite 行号当作跨版本身份。

公共绑定优先使用公共库提供的唯一 StableEntityKey，或具有提供方及角色命名空间的 ExternalId。相同稳定身份换行号后，标准名覆盖、新增别名、禁用名称及用户关系仍可延续。

公共库没有稳定身份、身份重复或拆分时，绑定退回“公共文件内容 SHA-256 + 当前行号”。这只适用于完全相同的公共版本；升级后用户需在公共覆盖页明确重新绑定。删除/拆分/缺失公共身份不会删除覆盖，也不会猜测绑定。被禁用的旧名称不会因异常绑定静默重新启用。公共库缺失时用户库独立可用。

历史 EhTagTranslation 自动推断不再作为作者身份依据；用户明确确认的记录保留。在线证据与外部编号按提供方命名空间区分，弱证据不覆盖已确认身份。同名多候选不自动选择第一条。身份冲突进入“待确认”，阻止自动创建或选择作者文件夹。

## 迁移与保存安全

首次迁移记录旧 TXT 指纹并保留未解析行，重叠分组进入冲突，不按名称重叠合并作者。JSON/TXT 导入会备份来源，重复导入同一内容不会重复创建实体；不同来源的旧整数 Id 不作为共同身份。

保存采用同目录唯一临时文件、写入落盘、重新解析验证，再原子替换。损坏 JSON、悬空关系、重复 ID 和未知 schema 阻止写入；替换失败保留原文件并报告失败，不回退为空库。迁移前保留 JSON/TXT 备份，日常替换保留 `.bak`。

恢复时先关闭程序，备份当前 JSON，再将选定备份复制回 `AuthorEntities.json`。保留公共库、设置及 Cache 目录。旧 TXT 可留作历史材料，无需删除。

## 索引与缓存

识别从实体数据派生别名索引，不维护第二份可编辑别名主库。公共索引按内容版本更新，打开用户实体页不会立即加载全部公共冲突。实体查询、文件名依赖和公共快照复用内存索引。

实体编辑更新内存识别版本；持久化识别和整理计划使用每个文件的作者依赖，仅失效关联名称/关系的记录。在线查询时间和查询状态不作为身份版本。源文件索引保留，不因作者编辑重新发现全部文件。公共内容更新重新验证公共依赖，避免跨版本复用旧结果。

## 实际验收

构建：`BUILD_EXE.cmd --no-pause`。回归：`Build/RUN_INCREMENTAL_CONTRACT_TESTS.cmd`、`Build/RUN_AUTHOR_LIBRARY_TESTS.cmd`。真实数据验收：`Build/RUN_AUTHOR_LIBRARY_TESTS.cmd bin/Release Docs/AuthorLibraryAcceptance/Final --skip-simulation`。测试复制用户库和持久索引到临时目录，公共库和实际目标目录只读，未执行归档移动；原始公共库、JSON、TXT、索引和设置字节校验不变。

真实样本包含 68,936 作者、94,280 查询键及 8,490 个已索引文件。最近一次完整对照结果详见 [验收记录](AuthorLibraryAcceptance/Final/results.md)：

- 公共冷索引 1,893 ms；10,000 次真实名称查询 400 ms（9,870 次解析成功、130 次正确保留歧义）。
- 首次整理规划 5,897 ms；首次计划及依赖写入 182 ms；持久重复计划读取 89 ms，8,490 条全命中，重算 0，源文件重新发现 0。
- 同样文件顺序、目标目录及设置下，迁移前后作者身份、目标和状态差异 0。
- 对比历史已保存计划有 41 条可解释差异：6 条实体冲突改为等待确认；其后 34 条作者身份不变但新作者分组位置改变；1 条已处于真实作者目录，恢复为“已在目标目录”。逐条证据保存在本机 `AuthorLibraryAcceptance/Final/prior-scan-differences.json`；该文件含实际路径和文件名，不提交到仓库。测试要求不存在未解释差异。
- 独立模拟 8,490 文件首次 83,474 ms，重复缓存扫描 54 ms；85 文件增量重算 1,011 ms，保留 8,405 条缓存。见 [模拟性能记录](AuthorLibraryAcceptance/performance.md)。计时为此工作区与本机样本，包含的工作量不同，不混作同一个指标。

功能回归覆盖实体/别名 CRUD、身份与角色隔离、关系确认/禁用/解除、删除引用保护、导入幂等、失败替换及损坏文件保护、公共换 ID/拆分/删除/缺失/重新绑定、禁用名延续、按文件缓存失效及临时实体保存。

界面验收使用 5,000 用户作者，在中英德三种语言及 100%/150% 字体缩放下实际构建并渲染。截图保存在 AuthorLibraryAcceptance。该检查为字体缩放渲染，不等同于真实 Windows DPI、多显示器或人工交互验收。
