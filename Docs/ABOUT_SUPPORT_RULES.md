# 关于 / 支持 / 反馈页面规则（V1.11.23）

## 页面职责必须分开

### 关于
只负责软件身份、版本、项目入口和反馈入口：
- 中文软件名：归归
- 英文品牌名：GuiGui
- 开发者：kendo
- 版本号独立一行显示
- GitHub 项目入口：按钮形式，不直接展示完整 URL
- 检查更新：保留按钮与未来交互位置；当前无分发地址，不执行实际检查或安装
- 社群反馈：归归反馈QQ群、GitHub 反馈
- 左下角：许可证

“关于”页面不显示赞赏二维码、爱发电、Ko-fi 或其他捐赠入口。

### 支持项目
只负责自愿支持入口：
- 微信赞赏码：优先读取 GitHub Pages 远程配置，失败时使用本地缓存，最后回退至 `Assets/SupportWeChat.png`
- 支付宝收款码：优先读取 GitHub Pages 远程配置，失败时使用本地缓存，最后回退至 `Assets/SupportAlipay.png`
- 爱发电：https://afdian.com/a/kendo
- Ko-fi：https://ko-fi.com/kendoyae
- Patreon：当前不显示

## 反馈入口

- “归归反馈QQ群”按钮始终先复制 QQ 群号 `1103654612`。
- Windows 桌面端不再使用 `mqqapi://`。V1.11.21 已内置群号 `1103654612` 对应的 QQ 官方 `qm.qq.com` 加群链接。
- `Assets/QQ_GROUP_JOIN_URL.txt` 作为可替换覆盖配置保留；未来 QQ 邀请链接失效时可只更新该文件。
- 点击“归归反馈QQ群”先复制群号，再打开 QQ 官方加群链接；打开失败时保留已复制群号并给出兜底提示。
- “GitHub 反馈”直接打开 `https://github.com/kendoyae/GuiGui-MangaAuthorSorter/issues`。
- 外部 URL 由用户点击后才打开，不在后台自动启动浏览器。

## 更新入口

- “检查更新”按钮当前仅保留 UI 与交互位置。
- 在正式提供发行清单、版本元数据、校验值和下载地址之前，不得伪造在线检查结果，也不得自动下载或替换程序文件。
- 后续真正接入更新功能时，应补充签名/哈希验证、失败回滚和用户确认流程。

## 许可证与公开说明

- 关于窗口左下角固定提供“许可证”按钮。
- 点击后打开 `LicenseForm`。界面按当前语言分为固定分类，不直接把双语原文全部塞入单个文本框。
- `LICENSE_NOTICES.txt` 继续作为完整双语公开说明随 Portable 发行包分发；许可证窗口提供“打开完整说明”按钮。
- 当前声明至少覆盖：软件版权、Everything / voidtools 集成、Danbooru 在线服务、Microsoft Windows / .NET Framework、外部链接与网络访问说明。
- 后续新增第三方库、二进制组件、网络 Provider 或更改项目许可证时，必须同步更新 `LICENSE_NOTICES.txt`。

## 支持边界

- 所有支持均为自愿，不影响软件任何功能或更新。
- 不因是否支持而改变功能可用性、更新权限、识别结果或联网行为。

## 二维码资源

- 固定配置入口为 `https://kendoyae.github.io/GuiGui-MangaAuthorSorter/donation.json`。
- 在线图片只接受 HTTPS，且域名必须为 `kendoyae.github.io`，路径必须位于 `/GuiGui-MangaAuthorSorter/` 下。
- 加载顺序固定为：远程最新版 → `DonationCache` 本地缓存 → EXE 内置备用图。
- 在线获取和缓存失败时不报错，也不阻止“支持项目”页面打开。
- 成功取得的配置与图片缓存在程序目录的 `DonationCache` 文件夹。
- 在线按钮只接受预设的爱发电和 Ko-fi HTTPS 域名，配置不得跳转到其他站点。
- 更新二维码时替换 Pages 上的图片并修改 `donation.json`；旧版 EXE 无需重新发布。

## UI 原则

- “帮助 → 关于”与“帮助 → 支持项目...”为两个独立入口。
- 两个窗口均使用 UiStyle，与其他二级窗口保持字体、背景、边框、按钮风格一致。
- 关于窗口应接近传统桌面软件 About 对话框：信息简洁、层级少、无需滚动。
- 多语言文案保持短、标准；URL、开发者名 kendo、GuiGui 标识不翻译。

## V1.11.21 支持页面布局

- 支持页面不使用“微信 / 支付宝 / 在线支持”三列等权布局。
- 上半区固定为微信赞赏与支付宝两个等宽二维码位；二维码视觉区域固定 240×240，缺失时使用同尺寸白底占位。
- 二维码容器不绘制额外灰色背景或边框；二维码本身就是主要视觉边界。
- 下半区为在线支持，爱发电与 Ko-fi 使用同一行、同高度按钮，并从左侧开始排列，不再居中分散。
- 不显示“点击按钮会使用默认浏览器打开对应支持页面”之类可由按钮行为直接表达的冗余说明。
- “所有支持均为自愿，不影响软件任何功能或更新”固定为全宽页脚说明；关闭按钮固定右下角。
- 多语言时按钮宽度可按文案扩展，但二维码尺寸、两层信息结构和页脚位置保持稳定。
