# 归归 / GuiGui - Ehentai MangaAuthorSorter

![软件截图](Assets/AppIcon256.png)如果你和我一样喜欢把作者按名字进行文件夹归档，那么归归非常适合你。

归归面向 Windows 的漫画作者与社团识别归档工具。归归会先扫描和识别文件名，再提供整理预览；只有经过确认后才会移动文件。软件识别规则基本基于Ehentai的下载默认名字，个别可能需要自行调整。软件内不提供任何下载，只基于本地文件进行归档整理。

## 主要功能

- 识别文件名中的作者、社团及别名
- 匹配已有作者目录，安全处理新作者与歧义候选
- 支持自定义文件类型、标签清洗和扫描排除规则
- Everything 可用时加速文件发现，不可用时自动回退文件系统扫描
- 保存整理历史，并在执行前检查目标冲突和磁盘空间
- 简体中文、英语、德语界面

## 快速开始

1. 选择需要扫描的“原始位置”。
2. 选择作者归档使用的“迁移位置”。
3. 点击“扫描预览”，检查识别作者、状态和目标目录。
4. 处理待确认项目，确认无误后执行整理。

![软件截图](Assets/README/001.png)

涉及大量文件时，建议先用少量文件验证规则，并保留必要备份。

## 下载与更新

归归通过 GitHub Releases 提供正式版本。程序可在“帮助 → 检查更新”或“关于归归”中查询新版本，并前往对应 Release 页面下载；当前不提供自动下载、静默安装或覆盖更新。

正式分发支持单 EXE。程序会按需创建用户设置、规则和历史数据文件；固定图标、使用说明、更新说明、许可证和支持二维码已内嵌。
